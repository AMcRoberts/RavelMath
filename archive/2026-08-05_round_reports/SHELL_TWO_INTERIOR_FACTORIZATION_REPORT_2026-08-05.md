# Shell-two interior factorization

The previous shell-two premise was represented only by a literal first-return graph and a finite topological rank. This round replaces that box-level object with the structural automaton dictated by the stepped-hyperplane carry source.

For shell radius two, every proper intermediate state lies in the strict interior cube

    I_n = {-1,0,1}^n.

A first-return edge factors exactly as

    boundary entry -> path in I_n -> first boundary exit.

`derive_shell_two_interior_factorization(n)` constructs:

- the exact interior carry automaton on `3^n` states;
- every boundary-to-interior entry;
- every interior-to-boundary exit;
- the induced first-return graph;
- an independent literal first-return graph for replay;
- a strict topological rank when the induced graph is acyclic.

The factorized and literal first-return graphs agree exactly for every tested dimension `n=2..7`. The shell-two ranks are also replayed edge by edge.

This is a substantive reduction of the universal shell-two theorem. The dimension-parametric proof no longer needs to reason about the full `5^n` coefficient box. It must prove acyclicity of a boundary relation generated by the uniform `3^n` interior carry grammar.

The remaining theorem is not represented by a Boolean premise in this operation. It is now the explicit structural statement:

    the boundary-entry/interior-carry/boundary-exit relation is acyclic for every n>=2.

The next implementation target is a dimension-shadow or recurrence on the interior carry grammar itself, with the boundary entry/exit roles transported alongside it.
