# Cycle characteristic-polynomial proof campaign

This backend closes the graph-spectrum seam from the certified code path.

The certificate-derived recurrent SCC is converted to the canonical shift-with-wrap
matrix. Rather than importing the endpoint identity, the backend realizes that matrix
as left multiplication by the root of `X^n - 1` in `AdjoinRoot (X^n - 1)`.

The proof chain is:

1. `AdjoinRoot.powerBasis` constructs the power basis generated by the root.
2. `PowerBasis.leftMulMatrix` derives the shift-with-wrap matrix entries.
3. `charpoly_leftMulMatrix` identifies its characteristic polynomial with the
   minimal polynomial of the generator.
4. `AdjoinRoot.minpoly_powerBasis_gen_of_monic` closes that minimal polynomial as
   `X^n - 1`.
5. The existing graph certificate converter reindexes the recurrent SCC to this
   canonical core and the block-charpoly backend contributes the transient `X` factor.

This is a new theorem campaign assembled from reusable machinery. The endpoint is not
inserted as raw proof text.
