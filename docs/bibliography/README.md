# Archived primary sources

## Gabor Frames of Totally Positive Functions: A Complete Characterization

Jaume de Dios Pont, Karlheinz Gröchenig, Lukas Liehr, Irina Shafkulovska,
and Mitchell A. Taylor, “Gabor Frames of Totally Positive Functions: A
Complete Characterization,” arXiv:2608.04992 [math.FA], submitted 2026-08-05.

- arXiv record: <https://arxiv.org/abs/2608.04992>
- DOI: <https://doi.org/10.48550/arXiv.2608.04992>
- Local full text: `de_dios_pont_grochenig_liehr_shafkulovska_taylor_2026_gabor_frames_totally_positive_complete_characterization.pdf`
- Local extracted text: `de_dios_pont_grochenig_liehr_shafkulovska_taylor_2026_gabor_frames_totally_positive_complete_characterization.txt`

The paper states a complete frame-set characterization for continuous,
integrable totally positive functions: the rectangular-lattice Gabor system
is a frame exactly when `alpha * beta < 1`. It also gives a sharp Kadets-type
theorem for the associated shift-invariant spaces and includes Lean 4 source.
